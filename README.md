# StockVibe

A financial dashboard web application that analyzes the "vibe" of a stock ticker through news processing and AI analysis.

## Features

- **Search Bar & History:** Easily search for stock tickers and quickly access the last 3-4 searched tickers. 
- **The "Vibe Card":** Color-coded "Vibe Meter" (from Red to Green) showing the current mood of the stock.
- **AI Analysis:** Read a quick 2-3 sentence summary on stock performance based on latest news, generated by Gemini AI.
- **Pros & Cons:** A two-column breakdown showing the "Bullish Drivers" and "Bearish Risks."
- **Market Voices:** Find out analyst sentiment extracted from recent headlines.
- **Headlines Feed:** A scrolling list of the raw news articles used for the analysis.

## Tech Stack

This project is partitioned into a separate frontend and server, designed to offer a dynamic but robust experience.

### Frontend
- **React (v19)** with **TypeScript** for robust component-based UI.
- **Vite** for fast, optimized builds.
- **Tailwind CSS (v4)** for rich, responsive, and modern styling.
- **React Router** for seamless navigation.

### Backend / Server
- **Node.js** with **Express** for building a robust API backend.
- **TypeScript** to maintain strict type-safety across requests.
- **Google Generative AI SDK** integration for AI processing and analysis.
